# Data

## WESAD: Wearable Stress and Affect Detection

This project uses the WESAD dataset for physiological signal analysis.

Dataset source:
  Schmidt et al. (2018)
"Introducing WESAD, a Multimodal Dataset for Wearable Stress and Affect Detection"

The dataset contains physiological signals collected from wearable devices, including:
  
  - Electrocardiography (ECG)
- Electrodermal activity (EDA)
- Respiration
- Temperature
- Acceleration

The data include multiple experimental conditions:
  
  - Baseline
- Stress
- Amusement

Raw participant data are stored locally and are not redistributed.
