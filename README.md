# Functional Physiology Analysis

## Overview

Physiological signals are dynamic measurements that contain important temporal information, yet many analyses reduce them to summary statistics.

This project investigates whether functional data analysis and machine learning methods can improve characterization and prediction of physiological states from time-series signals.

## Objectives

1. Preprocess physiological signals
2. Extract traditional physiological features
3. Represent signals using functional data analysis
4. Compare statistical and machine learning prediction approaches

## Methods

- Signal processing
- Heart rate variability analysis
- Functional principal component analysis
- Logistic regression
- Machine learning models

## Tools

- R
- tidyverse
- signal
- fda
- caret/tidymodels
